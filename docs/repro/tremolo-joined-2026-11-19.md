# 依頼 28（学習用の形）: 2 音トレモロの線を、両方の符幹につなげて描けるようにしてほしい

急がない。書き方と既定はそちらとオーナーの判断（REQUESTS「学習用の形の依頼」）。

## どんな形か

2 音トレモロ（`repeat tremolo N { a b }`）の線は、今の lysc と LilyPond の既定では**符幹から離して浮かせて**描く。
古い刷りでは、その線が**両方の符幹に端から端までくっついて**いる。見た目は「付点の音符 2 つを太い連桁 4 本でつないだもの」で、
連桁つきの短い音符（64 分の付点 2 つ）と見分けにくい。小節の長さを数えて初めてトレモロと分かる。

## 実譜の例

Kücken Op.47-3（Fr. Kistner 1711）の 60〜72 小節の 2 音トレモロは、すべてこの形で刷られている。
たとえば 6 頁 66 小節の左手の終わり: `<fis b>` と `dis'` が付点の頭（合わせて付点 4 分＝3/8）で、2 つの符幹を太い線 4 本がつなぐ。

切り抜き: `out/repro/tremolo-joined-2026-11-19-kuecken47-3-b66.png`（公開 repo には入れない。予備の台の原本）。

## 再現と比べた絵

| | ファイル | 絵 |
|---|---|---|
| 今の lysc | `docs/repro/tremolo-joined-2026-11-19.lys`（`repeat tremolo 12 { <fis b>64 dis'64 }` を 2 つ） | `out/repro/tremolo-joined-2026-11-19.cropped.png`（Release の lysc 0.16.0）: 線は符幹から離れて浮く。LilyPond の既定と同じ |
| LilyPond 2.26.0 | `docs/repro/tremolo-joined-2026-11-19-lp.ly`（手で書いた。1 小節目が既定、2 小節目が `\override Beam.gap = #0`、3 小節目が `\override Beam.gap-count = #0`） | `out/repro/tremolo-joined-2026-11-19-lp.cropped.png`: **`Beam.gap = #0` で線が両方の符幹につながり、紙と同じ形**。`gap-count = #0` は既定と変わらない |

LilyPond どおりの既定の絵は不具合ではない。

## OMR に要ること

1. **学習用の形**: 生成器でこの形を描ければ、検出器と読み手に「両方の符幹につながった太い線＋付点の頭＝2 音トレモロ」を学ばせられる。今は描けないので、生成譜にこの形が出ない。
2. **見分けにくさの証拠**: 人の目でも 64 分の付点 2 つと読める（オーナーが 66 小節で一度そう読んだ）。独立した読み手の homr は、Kücken の 60〜72 小節の 2 音トレモロを、頭ごとに書かれた値（付点 2 分など）で読み、正解の数え方と音価が割れる（予備の台の突き合わせ、HANDOFF の Kücken の節）。
   なお Kücken は予備の台で、今の読み手では一度も読んでいない（読ませない決まり）ので、今の読み手がこの形をどう読むかは確かめていない。
3. **正解の絵**: 正解はトレモロのまま書けるが、描き直しを紙と見比べるとき（Show Original Scan）に形が近い方が確かめやすい。

## 提案（決めるのはそちら）

- 曲全体で選べる形にする（例: `layout { tremoloBeams joined }`、`--set` で揺らせると生成器が使いやすい）。曲の途中で混ぜる必要はない。
- 絵は LilyPond の `\override Beam.gap = #0` と同じ。`lysc ly` はその 1 行を書く。
- 音価・MIDI・MusicXML は今と同じ（形だけ変わる）。既定は今のまま（書かない譜の絵は動かない）。
